# BUNA — React (Vite) menu site
Run: `npm install && npm run dev`. Deploy: push to GitHub and import in Vercel (auto-detects Vite), or run `vercel`.
Menu, prices, descriptions, add-ons (`opts:["Oat milk +€0.50"]`): edit `src/data.js`.
Photos: put WebP files in `public/images/` named like the item `id` (hero.webp, coffee.webp, ube-latte.webp, gallery-1.webp ...).
Order tried: your file -> Unsplash (REMOTE in data.js) -> drawn illustration. Hero ~1600px, cards ~900px, each under ~150 KB.
About text/footer placeholders live in `src/App.jsx`.
